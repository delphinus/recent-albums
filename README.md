# recent-albums

Mac の Music.app のライブラリから、最近追加したアルバムを追加日・再生回数・アートワーク付きで
iPhone に一覧する Web アプリ。タップすると iPhone のショートカット「アルバムを再生」を呼び、
iPhone の Music アプリで再生する。

iPhone の Music アプリの「アルバム」画面は追加順に並べられるが、追加日や再生回数は出ない。
それを補うためのもの。ライブラリは iCloud ミュージックライブラリで iPhone と同期している前提。

## 表示するもの

- 追加日 (アルバム内の最も新しい曲)
- 再生回数: 先頭トラックの回数を「聴き始めた回数」、最終トラックの回数を「完走した回数」として出す。0 回なら「未再生」
- 最後に再生した日、曲数、合計時間
- 「未再生」とジャンルで絞り込める。和名のジャンル (ハードコア 等) は英名にまとめて表示する

## 必要なもの

- macOS と Music.app
- Python 3.10 以上 (標準ライブラリだけで動く)

## Mac 側

```sh
./install.sh
```

LaunchAgent `dev.delphinus.recent-albums` を入れて起動する。8765 番ポートで待ち受け、
LAN 内から `http://<Mac のホスト名>.local:8765/` で開ける。認証は無いので、LAN の外には出さないこと。

- 初回は Music.app の操作を許可するダイアログが出る
- ログ: `~/Library/Logs/recent-albums.log`
- キャッシュ: `~/Library/Caches/recent-albums/` (一覧とアートワーク。アートワークを差し替えたときは消せば取り直す)

一覧は 1 時間ごとに裏で取り直してキャッシュに置き、開いたときはそれを返す (画面に取得時刻を出す)。
「更新」ボタンを押すとその場で取り直す。Music.app が起動していないときは定期取得を見送る。

手で動かすなら `python3 server.py [--port 8765] [--days 365] [--interval 3600]`。

## iPhone 側のショートカット「アルバムを再生」

名前は正確にこのとおりにする。

1. 「ミュージックを検索」: フィルタ「アルバム」「が次と一致」「ショートカットの入力」、並べ替え「トラック番号」「昇順」
2. 「ミュージックを再生」: シャッフル「オフ」、リピート「なし」
3. (任意) 「アプリを開く」: ミュージック

Safari でページを開き、共有メニューから「ホーム画面に追加」するとアプリのように使える。

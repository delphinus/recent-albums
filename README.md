# recent-albums

Mac の Music.app のライブラリから、最近追加したアルバムを追加日・再生回数・アートワーク付きで
iPhone に一覧する Web アプリ。アートワークの右下の ▶ を押すと iPhone のショートカット「アルバムを再生」を呼び、
iPhone の Music アプリで再生する。

iPhone の Music アプリの「アルバム」画面は追加順に並べられるが、追加日や再生回数は出ない。
それを補うためのもの。ライブラリは iCloud ミュージックライブラリで iPhone と同期している前提。

## 表示するもの

- 追加日 (アルバム内の最も新しい曲)
- 再生回数: 先頭トラックの回数を「聴き始めた回数」、最終トラックの回数を「完走した回数」として出す
- 再生状態: 先頭と最終の両方のトラックを聴いていれば「再生済み」、片方だけなら「再生途中」、どちらも 0 回なら「未再生」
- 最後に再生した日、曲数、合計時間
- 再生状態・DJ mix・ジャンルで絞り込める。和名のジャンル (ハードコア 等) は英名にまとめて表示する

## 中身を見る

アルバムやプレイリストの行 (▶ 以外の部分) を押すと、曲の一覧を開く。曲ごとに長さと再生回数を出し、
上の「再生」ボタンからも流せる。すぐに流したいときは、一覧の ▶ を押せば中身を開かずに再生する。

- 戻るボタンのほか、iPhone の画面の端から戻る操作でも一覧へ戻る。一覧のスクロール位置も戻る
- `?album=<アルバム名>` / `?playlist=<id>` で中身を直接開ける
- アーティストは、アルバムのアーティストと違う曲 (コンピレーションや DJ mix) にだけ出す
- プレイリストは先頭の 500 曲まで出す。曲の情報は一覧と同じ間隔で取り直すので、取得前のキャッシュでは曲が出ない

## 検索とプレイリスト

- 上部の検索欄で、ライブラリ全体のアルバム (名前・アーティスト) とプレイリスト (名前・フォルダ) を探せる。
  空白で区切った語をすべて含むものが出る。全角・半角、大文字・小文字は区別しない
- 「プレイリスト」タブで、プレイリストをフォルダの順に一覧できる
- プレイリストのアイコンは、含む曲のアルバムのアートワークを曲順で 4 枚選んで 2×2 に並べる。4 枚に満たなければ先頭の 1 枚を出す。
  Music.app のスクリプトからはプレイリストに設定したアートワークを読めないので、設定してあっても使わない
- アルバムはショートカット「アルバムを再生」、プレイリストはショートカット「プレイリストを再生」で流す。
  どちらも名前で探すので、同じ名前のアルバムやプレイリストが複数あると、どれが流れるかはショートカット次第になる

ライブラリ全体の一覧も 1 時間ごとに取り直す (「更新」ボタンでも取り直す)。プレイリストは iTunesLibrary
フレームワークで読むので、Music.app で作ったばかりのものは少し遅れて出ることがある。

## 月間ランキング

Apple Music が月初に作る「前月によく聴いた曲」のプレイリストを、ライブラリ全体で作る。Apple のものは Apple Music の
カタログの曲しか数えないが、こちらはリッピングした曲や購入した曲も同じように数える。逆に、ライブラリに
追加していないカタログの曲は数えられない。

- 毎月 1 日に LaunchAgent `dev.delphinus.recent-albums-monthly` が `monthly_top.py monthly` を回し、
  フォルダ `[! Monthly Top]` に「2026-10 Monthly Top」のような手動プレイリストを作る
- 入れるのは 2 回以上聴いた曲の上位 50 曲。DJ mix の曲 (下の「DJ mix の判定」と同じ基準) は入れない
- 作ったら Slack に知らせる。リンクを開くとリプレイの画面 (`/replay?month=2026-10`) が出る。Apple Music の
  リプレイと同じ並びで、総再生時間・トップアーティスト・トップソング・トップアルバムを出し、下の再生ボタンで
  ショートカット「プレイリストを再生」を呼ぶ
- プレイリストの画面の先頭に、年間と月ごとのカードを Apple Music のリプレイのように並べる。カードを押すとリプレイの画面を開き、
  右上の ▶ でそのプレイリストを流す
- 年間のリプレイ: 月が変わるたびに、年のはじめから最新の控えまでの上位 100 曲で「2026 Replay」を作り直す。
  リプレイの画面の最後のカードから流せる。年のはじめの控えが無い年は、最も古い控えから数える
- プレイリストから手で外した曲は `~/Library/Application Support/recent-albums/exclude.json`
  (`{"<persistentID>": "理由"}`) に書いておく。作り直しや年間の集計で戻らない
- 再生時間・アーティスト・アルバムには DJ mix も含める (トップソングとプレイリストには含めない)。
  連名の曲は、分けた名義のどれかがライブラリに単独で居るときだけ、名義ごとに数える

Music.app は曲ごとの累計の再生回数しか持たず、いつ聴いたかは持たない。そこで月初に累計の控えを
`~/Library/Application Support/recent-albums/playcounts/` に取り、前月初めの控えとの差をその月の回数とする。
途中で飛ばした曲は Music.app が数えないので、こちらでも数えない。

控えが月の 1 日ちょうどに取れていないとき (Mac が寝ていた等) は、1 日に最も近い控えを使う。両端のどちらかが
3 日より離れていれば、プレイリスト名に実際の期間を添える (例: 「2026-08 Monthly Top (8/24〜)」)。

```sh
python3 monthly_top.py build 2026-10 --dry-run    # 集計だけ見る
python3 monthly_top.py build 2026-10 [--notify]   # 作り直す (同じフォルダの同じ名前のものを置き換える)
python3 monthly_top.py year 2026                  # 年間のリプレイを作り直す
python3 monthly_top.py build 2026-10 --stats-only # プレイリストに触れず、画面用の集計だけを作り直す
python3 monthly_top.py import-tsv <tracks.tsv> --date 2026-10-04   # 別に取っておいた再生回数の一覧から控えを作る
```

設定はリポジトリの外に置く。どちらも無ければ Slack に送らない、またはリンクを付けない。

- `~/.config/recent-albums/slack-webhook`: Incoming Webhook の URL (1 行。`chmod 600`)
- `~/.config/recent-albums/public-url`: この Web アプリを外から開く URL (1 行)。Slack は `shortcuts://` をリンクにしないので、Web アプリの画面を経由する
- ログ: `~/Library/Logs/recent-albums-monthly.log`

## シリーズ

「シリーズ」タブで、シリーズごとのフォルダを並べる。アイコンには新しく追加した 4 枚のアートワークを出す。

- フォルダをタップすると、そのシリーズのアルバムを番号の昇順に並べる
- フォルダの右上のボタン (開いた画面では「ランダムに再生」) で、シリーズ内の 1 枚をランダムに選んで流す。
  選んだアルバムに「<アルバム名> Mix」のプレイリスト (下の「DJ mix の判定」) があれば、そちらを流す
- 検索でもシリーズ名で探せる

ライブラリにはシリーズを示す情報が無いので、アルバム名から判定する。名前の中の最初の番号より前の部分
(`Otographic Arts 029` なら `Otographic Arts`) が同じアルバムが 3 枚以上あれば、1 つのシリーズとみなす。

- 番号の直前の `Volume` `Vol.` `Episode` `Part` `Disc` などや、`,` `-` `#` `(` は名前に含めない。
  `Assorted Trance Volume 17` と `Assorted Trance, Vol. 3` は同じシリーズになる
- `Asot 893 - A State of Trance Episode 893` のように、略称と番号の後ろに同じ番号の正式な名前が続くものは、後ろの名前で数える
- 名前の先頭が番号のものや、`R4` `Trance4nations` のように語の中にある数字は番号とみなさない
- 年 (`Westfest 2013`) も番号として扱う。通し番号と年の両方があるシリーズでは、年のものが後ろに並ぶ

## DJ mix の判定

次のどちらかに当てはまるアルバムを DJ mix とみなす。

- プレイリスト「DJ Mix」に、そのアルバムの曲が入っている。一部の曲だけが入っていれば「一部が mix」と表示する
- アルバム名に `Mix` / `Megamix` / `Mixed by` が単語として入っている。ただし ` - Single` / ` - EP` で終わるものと、`(Extended Mix)` のような曲や版の名前の中にあるものは除く

アルバム名で判定できない DJ mix は、プレイリスト「DJ Mix」に入れる。iPhone でもアルバムの「…」から「プレイリストに追加」で入れられる。
入れたものは次の定期取得か「更新」ボタンで反映される。

一部が mix のアルバムは、mix の部分だけを入れたプレイリストを「<アルバム名> Mix」の名前で作っておくと
(例: 「Upfront & Vocal Forever Mix」)、一覧に「mix だけ」ボタンが出る。押すとショートカット「プレイリストを再生」で
そのプレイリストを流す。

全体が DJ mix のアルバムでも、同じ名前のプレイリストを作れば一部だけを流せる。ゲスト回の放送で
ゲストのパートだけを聴きたいとき (例: 「Keeping The Rave Alive 621 Mix」) に使う。ボタンは「一部だけ」と出る。

## 必要なもの

- macOS と Music.app
- Python 3.10 以上 (標準ライブラリだけで動く)
- Xcode Command Line Tools (プレイリストを読む `playlists.swift` を `swift` で動かす)

## Mac 側

```sh
./install.sh
```

LaunchAgent `dev.delphinus.recent-albums` (Web アプリ) と `dev.delphinus.recent-albums-monthly` (月間ランキング) を入れて起動する。8765 番ポートで待ち受け、
LAN 内から `http://<Mac のホスト名>.local:8765/` で開ける。認証は無いので、LAN の外には出さないこと。

- 初回は Music.app の操作を許可するダイアログが出る
- ログ: `~/Library/Logs/recent-albums.log`
- キャッシュ: `~/Library/Caches/recent-albums/` (一覧とアートワーク。アートワークを差し替えたときは消せば取り直す)

一覧は 1 時間ごとに裏で取り直してキャッシュに置き、開いたときはそれを返す (画面に取得時刻を出す)。
「更新」ボタンを押すとその場で取り直す。Music.app が起動していないときは定期取得を見送る。

手で動かすなら `python3 server.py [--port 8765] [--days 365] [--interval 3600]`。

## iPhone 側のショートカット「アルバムを再生」

名前は正確にこのとおりにする。

1. 「ミュージックを検索」: フィルタ「アルバム」「が次と一致」「ショートカットの入力」、並べ替え「トラック番号」「昇順」
2. 「ミュージックを再生」: シャッフル「オフ」、リピート「なし」
3. (任意) 「アプリを開く」: ミュージック

## iPhone 側のショートカット「プレイリストを再生」

「mix だけ」ボタンで使う。名前は正確にこのとおりにする。

1. 「ミュージックを検索」: フィルタ「プレイリスト」「が次と一致」「ショートカットの入力」
2. 「ミュージックを再生」: シャッフル「オフ」、リピート「なし」
3. (任意) 「アプリを開く」: ミュージック

Safari でページを開き、共有メニューから「ホーム画面に追加」するとアプリのように使える。
